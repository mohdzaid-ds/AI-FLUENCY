## 2. Case Studies

### 2.1 Fast API TO_DO List

#### The Problem

I was new to backend development and FastAPI.
My task was to build a to-do list API with full CRUD operations — Create, Read, Update, Delete. Before writing code, I had to actually understand how a backend works: going through documentation, examples, and research.

#### What I Did
built the CRUD operations one by one. The key decision was how to store the to-do items — a list or a dictionary.
A list would've been simple to iterate for GET requests, but a dictionary was more effective for this case: it let me handle lookups by ID directly, including returning a clean 404 when an ID didn't exist.
As the project grew, I also split the CRUD operations into separate files instead of keeping everything in one main.py — it made the codebase easier to work with, especially as a beginner.


#### What Came of It

The API works fully — Create, Read, Update, and Delete all run and respond correctly. Along the way I hit real issues, not just tutorial steps: a "not found" error turned out to be a PowerShell quirk, which I confirmed and fixed by testing with curl instead.
